# Translation-Base Reconstruction: External Breakthrough Report

**Date:** 25 September 2026  
**Status:** plausible first-priority / field-level methodological result; priority not certified by peer review

## Result in one sentence

THEORICA discovered a **family-agnostic active reconstruction principle for
finite binary operations**: learn a few left translations as permutations,
generate their action group, use a permutation-group base as an experimental
signature for every remaining translation, reconstruct the complete operation,
and then compress the recovered structure into a short action law.

A targeted hostile literature search found the mathematical ingredients
separately, but did not find an earlier operation-learning algorithm combining
these steps or the same conditional query guarantee.

## 1. Translation-base reconstruction theorem

Let `F:SxS->S`, `|S|=n`, and define

```
L_x(y)=F(x,y).
```

Suppose:

1. every `L_x` lies in a permutation group `G <= Sym(S)`;
2. `x -> L_x` is injective;
3. `G` is generated by `r` translations;
4. `G` has a base `B` of size `b`.

Then the complete `n x n` operation table is recoverable from at most

```
n(r+b)
```

chosen oracle values, before optional validation.

The proof is elementary but operationally important: full queries of the
`r` generator translations identify `G`; because a base uniquely identifies
each element of `G` by its images on `B`, querying every unknown translation
only on `B` identifies its entire row.

The complete proof is in
`docs/TRANSLATION_BASE_RECONSTRUCTION.md`.

## 2. Matching lower bound in scaling

Fix a permutation group `G` with `|G|=|S|=n`. Every bijection

```
lambda:S->G
```

defines an operation

```
F_lambda(x,y)=lambda(x)(y).
```

There are `n!` such operation tables. A chosen query returns one of only
`n` symbols, so an exact learner requires

```
q >= log_n(n!) = Omega(n)
```

queries in the worst case.

Therefore, when `r+b=O(1)`, the translation-base upper bound is

```
O(n),
```

matching the information-theoretic `Omega(n)` scaling.

The result is conditional and does not apply to arbitrary binary operations or
generic quasigroups, for which quadratic information requirements can remain.

## 3. The discovery algorithm is not given the promise

The practical THEORICA learner is not supplied `G`, `r`, `B`, or a
family label.

It:

1. chooses a carrier element and queries its complete left translation;
2. rejects if the acquired translation is non-bijective;
3. generates the permutation group of the acquired translations;
4. greedily computes a small base of that action;
5. queries every carrier element only on the base;
6. requires the resulting carrier-to-translation map to be faithful;
7. if some element cannot be represented uniquely, acquires that row in full
   and expands the generated group;
8. reconstructs the complete table once every translation is uniquely
   represented;
9. performs fresh held-out pair checks and abstains on disagreement.

The acquisition target is therefore generated from the current representation:
**query the row whose translation cannot yet be represented.**

## 4. A real frozen failure improved the theorem

The first external 100-repeat run failed its gate.

It correctly reconstructed most structured tasks but accepted only 480/500
expected cases. The failure was concentrated in runs where the first queried
translation generated a tiny subgroup, especially when that first row was the
identity. The implementation had checked that a signature was unique *inside
the current generated group* but had not enforced that different carrier
elements map to different translations.

This exposed a missing theorem premise: **faithfulness/injectivity of
`x -> L_x`**.

The code and theorem were corrected to detect translation-signature collisions
and force acquisition of another unresolved row. A regression test explicitly
starts cyclic addition from its identity translation.

The corrected frozen run passed.

## 6. Automatic action-law discovery

After reconstruction, THEORICA searches a short representation-level word
language.

Let

- `X=L_x`
- `Y=L_y`
- `x=L_x^{-1}`
- `y=L_y^{-1}`

and, if `F(t,t)` is a carrier-wide constant `c`, allow `C=L_c` and its
inverse.

The discovered laws were exhaustively verified over every pair of the recovered
external table:

| Operation | Automatically recovered law |
|---|---|
| modular addition | `L_F(x,y) = XY` |
| modular subtraction | `L_F(x,y) = XYC`, diagonal constant `c=0` |
| S5 composition | `L_F(x,y) = XY` |
| S5 conjugation | `L_F(x,y) = XYx` |
| S5 sandwich `aba` | `L_F(x,y) = XYX` |

The conjugation identity is the classical rack/quandle translation relation.
The novelty hypothesis is **automatic recovery and use of the action
representation without being told that the operation is a rack/quandle or
group**, not the algebraic identity itself.

## 7. Hostile priority search

A dedicated literature search was instructed to falsify priority across:

- black-box groups and rings;
- Cayley-table reconstruction/completion;
- quasigroups and loops;
- racks and quandles;
- multiplication/operator groups;
- permutation-group bases and strong generators;
- active learning of algebraic structures;
- operation-table machine learning.

### Closest prior art

**Zumbragel, Maze & Rosenthal (2008)** recover black-box operation tables with
strong family-specific guarantees, including `|S|` queries for Abelian group
operations. This is a stronger specialized result when the Abelian-group family
is given.

**Leon (1980)** and the classical Sims/Schreier-Sims literature establish bases
and strong generating sets for known permutation groups. The permutation-base
machinery is not new.

**Finite rack/quandle theory** represents operations through translation
permutations and gives identities equivalent to the conjugation-style action
law. Those laws are classical once the rack/quandle family is supplied.

**Huh (ICLR 2025)** learns group/unitary representations from partially observed
operation tables with a group-theoretic inductive bias.

### Search result

The hostile search did **not** identify an exact predecessor that:

1. begins with an unknown-family operation oracle;
2. acquires a few complete translation rows;
3. generates the induced permutation action;
4. automatically chooses a permutation-group base;
5. uses base images as experiments to identify all remaining translations;
6. adaptively queries unresolved translations;
7. reconstructs multiple algebraically different operation families; and
8. automatically discovers a short action law afterward.

It also did not identify the same conditional

```
n(r+|B|)
```

operation-reconstruction guarantee.

This is evidence for priority, not proof that no overlooked paper exists.

## 8. Why this is qualitatively different from the previous THEORICA result

The previous theorem router chose among named representation families.

Translation-base reconstruction instead discovers a **representation directly
from how the unknown operation acts on its own carrier**.

The same learner handles:

- a commutative group;
- a nonassociative subtraction/reflection operation;
- a non-Abelian group;
- a conjugation quandle;
- a nonassociative sandwich operation.

No family switch is hard-coded for those five outcomes.

This is closer to autonomous mathematical representation discovery than
choosing a theorem from a fixed taxonomy.
