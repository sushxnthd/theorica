# Contributing

THEORICA is research software. Contributions should preserve reproducibility and claim boundaries.

1. Open an issue describing the scientific or engineering motivation.
2. Add deterministic tests for behavior changes.
3. Do not tune against frozen holdout seeds.
4. New external benchmark claims must record upstream repository SHA, environment, exact command, raw outputs, and whether the run is native or source-derived.
5. Physical experiments must preserve raw append-only logs.
