# Four-vertex additive arrangement law

## Smallest supported claim

For a certified additive finite robust game with exactly four ambiguity
scenarios, THEORICA can compute an exact minimax value, nature distribution,
and executable policy without enumerating the Cartesian joint-action space.

If `L` is the number of distinct component-local action-tie hyperplanes, the
dual minimum is attained among at most

\[
\binom{L+4}{3}
\]

tetrahedral arrangement candidates.  The recovered policy has support at most
four.  The candidate count depends on the fixed ambiguity dimension and local
action ties, not on `product_t |A_t|`.

## Proof sketch

Write nature's distribution as `q in Delta_4`.  Additivity gives the exact
dual

\[
D(q)=\sum_t\max_{a_t}\langle q,u_{t,a_t}\rangle.
\]

Each component maximum is convex piecewise affine.  Its cells are cut only by
equalities between two actions of the same component.  On every cell of the
common arrangement, `D` is affine.  A nonempty minimum face therefore contains
an arrangement vertex; degeneracy merely enlarges that face.  In the
three-dimensional simplex, a vertex is generated by three independent
boundaries chosen from the `L` tie hyperplanes and four simplex facets, giving
the stated binomial upper bound.  At the minimizing `q`, only locally tied
actions can have positive primal mass.  Finite minimax/LP duality supplies a
basic feasible primal solution with support at most four.  The implementation
constructs that witness exactly with rational arithmetic.

The same argument suggests the fixed-`m` bound `binom(L+m,m-1)`, but this run
implements and validates only `m=4`.

The symmetry reduction quotients only action ordering, component ordering, and
the 24 scenario permutations.  All 65,536 ordered cases remain counted and
hashed in a deterministic order.

The scaling witness has 18 components and four actions per component.  Its
Cartesian space contains `4^18 = 68,719,476,736` joint actions.  The production
planner uses six distinct local tie hyperplanes, realizes 15 candidates against
the bound 120, and returns a valid four-support policy.

## Adversarial boundary

Additivity is necessary.  Consider identical all-zero local component data.
One global game may assign every joint action payoff vector zero; another may
add a cross-component bonus `(1,1,1,1)` only to joint action `(0,0)`.  Their
local inputs are identical, while their robust values are 0 and 1.  No planner
using only local payoff vectors can distinguish them.  Production therefore
requires `payoff_additive_certified=True`, rejects malformed four-scenario
inputs, and abstains when tied joint responses exceed its exact recovery cap.

## Independent verification

`scripts/audit_four_vertex_additive_arrangement.py` imports no THEORICA code.
It separately enumerates tetrahedral intersections with a determinant solver,
compares component-local and expanded joint-action arrangements on every
symmetry class, reconstructs all ordered-case counts, reopens all 40 holdouts,
and checks the scaling certificate.

## Novelty and priority audit

Hyperplane arrangements and their fixed-dimensional polynomial complexity are
classical; Edelsbrunner, O'Rourke, and Seidel give an optimal arrangement
construction in fixed dimension (SIAM J. Comput. 15(2), 1986, DOI
`10.1137/0215024`).  Fixed-dimensional linear programming is also classical,
including Megiddo's three-dimensional algorithm (SIAM J. Comput. 12(4), 1983,
DOI `10.1137/0212052`).  Convex separable piecewise-linear programming predates
this work as well (Fourer, Mathematical Programming 41, 1988, DOI
`10.1007/BF01580769`).

Accordingly, this is not presented as a new general arrangement, minimax, LP,
or support theorem.  The defensible THEORICA contribution is the explicit
product-free composition law, exact executable certificate, fail-closed API,
and exhaustive/prospective validation for four ambiguity scenarios.

## Limitations

- Only finite, exactly rational, certified additive games are covered.
- Runtime remains polynomial in local tie count only because scenario count is
  fixed; `binom(L+m,m-1)` is not efficient when `m` grows.
- Policy recovery currently enumerates tied joint responses and deliberately
  abstains above a configurable cap.
- Cross-component payoff terms, sequential games, approximate payoffs, and
  continuous ambiguity sets are outside the theorem.
- The empirical sweep is exhaustive only for two two-action components with
  binary four-scenario payoffs; larger shapes are prospective sampled holdouts.
