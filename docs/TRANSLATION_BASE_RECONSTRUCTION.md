# Translation-Base Reconstruction for Unknown Finite Operations

**Draft theorem note — 25 September 2026**

## Problem

Let `S` be a finite carrier with `|S| = n` and let

```
F : S x S -> S
```

be an unknown binary operation accessible only through chosen oracle queries.

For each `x in S`, define its left translation

```
L_x(y) = F(x,y).
```

Many familiar algebraic operations have highly structured left translations:

- a group law gives regular left-multiplication permutations;
- subtraction on a finite cyclic group gives reflections;
- conjugation gives inner automorphisms;
- rack/quandle operations are encoded by translation permutations;
- sandwich laws such as `F(x,y)=xyx` induce a compact permutation action.

The key question is whether the operation table can be recovered without first
being told which named algebraic family generated it.

## Theorem 1: Translation-base reconstruction

Assume there exists a permutation group

```
G <= Sym(S)
```

such that:

1. every left translation `L_x` lies in `G`;
2. the map `lambda : x -> L_x` is injective;
3. `G` is generated by translations
   `L_{g_1}, ..., L_{g_r}`;
4. `B = {b_1,...,b_m}` is a base for the action of `G` on `S`.

Then the complete operation table of `F` can be reconstructed from at most

```
n(r + m)
```

oracle values, before optional validation queries.

### Proof

Query each generator row completely. This costs `rn` values and determines
the generating permutations `L_{g_1},...,L_{g_r}`, hence the permutation
group `G`.

Because `B` is a base, the point-image map

```
sigma_B : G -> S^m,
sigma_B(g) = (g(b_1),...,g(b_m))
```

is injective: if two group elements have the same image tuple on every point of
the base, their quotient fixes `B` pointwise, so it is the identity.

For every `x in S`, query only

```
F(x,b_1),...,F(x,b_m).
```

These are exactly the signature

```
sigma_B(L_x).
```

Since `L_x in G` and `sigma_B` is injective, this signature uniquely
identifies the entire permutation `L_x`. Repeating for all `n` carrier
elements costs at most `mn` queries and reconstructs all rows, hence every
entry `F(x,y)=L_x(y)`.

The total is at most `n(r+m)`. □

## Corollary: linear-query recovery for bounded generator rank and base size

For any family of finite operations satisfying the theorem with

```
r + m = O(1),
```

the full `n^2` operation table is recoverable from only

```
O(n)
```

chosen oracle queries.

This does not contradict quadratic lower bounds for arbitrary quasigroups or
arbitrary binary operations because the theorem imposes a compact
translation-action promise.

## Theorem 2: information-theoretic linear lower bound

The linear dependence on `n` cannot in general be improved to sublinear
query complexity, even inside a compact translation-action family.

Fix a permutation group `G <= Sym(S)` with

```
|G| = |S| = n.
```

For every bijection

```
lambda : S -> G,
```

define an operation

```
F_lambda(x,y) = lambda(x)(y).
```

Each operation has bijective, faithful left translations, and its set of left
translations is exactly `G`. There are therefore

```
n!
```

distinct operation tables in this promise class.

### Proposition

Any exact chosen-query learner that identifies every operation in this class
requires, in the worst case,

```
q >= log_n(n!)
```

oracle queries. Hence `q = Omega(n)`.

### Proof

A single oracle answer is one element of an `n`-element carrier, so a depth
`q` deterministic query tree has at most `n^q` answer transcripts. Exact
identification of all `n!` possible operations requires

```
n^q >= n!.
```

Therefore

```
q >= log_n(n!).
```

By Stirling's approximation,

```
log_n(n!)
= (n log n - n + O(log n)) / log n
= n - n/log n + O(1),
```

which is `Omega(n)`. The same transcript-counting argument applies to
zero-error randomized learners after conditioning on their internal
randomness. □

### Consequence

When the required number of translation generators `r` and permutation-base
size `m` are bounded constants, Theorem 1 gives

```
q <= n(r+m) = O(n),
```

while Theorem 2 supplies an `Omega(n)` lower bound on a natural subclass.

Thus translation-base reconstruction is **order-optimal in oracle-query
scaling** for bounded-rank, bounded-base promise families.

This statement concerns the selected-query model. It does not imply optimality
against passive table completion, and it does not say the constants are
optimal.

## Discovery rather than a supplied promise

The implemented THEORICA procedure is deliberately not handed `G`, `r`,
`B`, or an algebraic family label.

It proceeds adaptively:

1. query one full left translation;
2. reject immediately if it is not bijective;
3. generate the permutation group induced by the queried translations;
4. compute a small base for the generated action;
5. query every unknown translation only on the base;
6. if a translation signature cannot be represented uniquely, query that
   translation in full and add it to the generator set;
7. repeat until every carrier element has a unique action signature;
8. reconstruct the complete operation table;
9. test fresh unqueried entries and abstain on disagreement.

Thus unresolved elements are themselves the acquisition rule: a full new row is
requested only when the current action representation cannot explain its base
signature.

## Statistical limitation

The theorem is exact **conditional on** the promise that every true
`L_x in G`.

The discovery algorithm does not know that promise in advance. Matching a base
signature only proves uniqueness *within the current generated group*, not
membership of an arbitrary unknown function in that group.

Therefore the empirical system uses held-out oracle checks after reconstruction.
If the reconstructed table differs from the true operation on an
`epsilon` fraction of uniformly sampled pairs, `v` independent validation
queries miss all errors with probability at most

```
(1 - epsilon)^v.
```

External benchmark scoring additionally compares the reconstruction with the
complete hidden table after the experiment, but that scoring information is not
available to the learner.

## Action-law compression

After a translation-action representation is reconstructed, THEORICA searches a
small representation-level language rather than a named algebraic taxonomy.

Let

- `X = L_x`,
- `Y = L_y`,
- `x = L_x^{-1}`,
- `y = L_y^{-1}`.

If the diagonal `F(t,t)` is a carrier-wide constant `c`, it also permits
`C=L_c` and `c=L_c^{-1}`.

The system searches short words `W(X,Y,...)` and verifies whether

```
L_{F(x,y)} = W(L_x,L_y,...)
```

for every pair in the reconstructed carrier.

On the external BOC family the expected short laws include:

- group/addition composition: `L_{F(x,y)} = L_x L_y`;
- conjugation: `L_{F(x,y)} = L_x L_y L_x^{-1}`;
- sandwich `xyx`: `L_{F(x,y)} = L_x L_y L_x`;
- cyclic subtraction: a length-three law using the translation of the
  discovered diagonal constant.

These identities are *outputs* of the representation search, not family labels
supplied to the learner.

## Relation to prior art

The components have deep prior art:

- permutation-group bases and strong generating sets are classical;
- black-box group operation recovery has family-specific subquadratic and
  linear-query algorithms;
- quasigroup, rack, and quandle theory uses multiplication/operator groups;
- finite racks/quandles admit permutation representations with translation
  identities;
- table completion and critical-set theory study how partial algebraic tables
  determine full structures.

A targeted hostile literature search on 25 September 2026 did **not** identify
an earlier algorithm combining:

1. unknown-family chosen-query operation learning;
2. acquisition of a few translation rows;
3. automatic generation of their permutation action;
4. base construction used as an experimental signature;
5. adaptive acquisition of unresolved translations;
6. exact table reconstruction across multiple algebraic families; and
7. automatic compression into an action identity.

This is a priority hypothesis, not proof of first publication. The strongest
classical threat is the combination of standard permutation-group base
machinery with family-specific multiplication-group theory.

## Falsification conditions

The proposed contribution should be rejected or narrowed if any of the
following is found:

1. an earlier operation-learning algorithm already uses queried translation
   generators plus permutation-group bases to identify all unknown rows;
2. a prior family-agnostic algorithm has the same conditional
   `n(r+|B|)` reconstruction guarantee;
3. external operations that satisfy the stated compact-action assumptions
   systematically fail the adaptive procedure;
4. false acceptance remains common under sparse adversarial corruption;
5. the action-law compression is already standard as an automatic inference
   procedure rather than family-specific algebraic theory.
