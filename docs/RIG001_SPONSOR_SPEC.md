# Rig 001 sponsor specification

## Sponsorship ask
₹25,000 or in-kind equivalent to build, characterize and document one reproducible autonomous optics rig.

## What the sponsor enables
- a real Reality-Gap test of a frozen THEORICA scientist;
- public hardware designs and measurement protocol;
- raw run traces and validation data;
- acknowledgement in the public technical report, with no influence over scientific conclusions.

## Acceptance gates before benchmark use
1. 50-cycle home repeatability characterization.
2. Dark-noise characterization and no detector rail clipping.
3. LED warm-up/drift curve.
4. Forward/reverse angle sweeps to quantify mechanical hysteresis.
5. Three repeated full optical sweeps.
6. Calibration file frozen before AI trials.

## Sponsor deliverables
- BOM and receipts;
- build photographs;
- firmware/host commit hashes;
- calibration dataset;
- official run videos/logs;
- concise outcome report.
