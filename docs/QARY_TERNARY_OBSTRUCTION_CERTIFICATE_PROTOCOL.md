# Ternary obstruction lower-bound certificate protocol

## Frozen target

At level costs `(1,3,1)`, use the ten-word family consisting of the binary
cube `{0,1}^3` and the canonical aligned pair `(2,0,0)`, `(2,1,0)`.
The query model remains arity three, depth three, four copies per prefix,
one substitution, one recognized erasure, and a middle-level first action.

The primary claim is that budget 17 is infeasible. This run will not count
another solver rejection as a proof mechanism. It must emit a finite
adversarial refutation DAG whose nodes are exact game states and whose edges
show, for every admissible planner query, one legal response that remains
refuted at the residual budget.

## Certificate rules

A refutation node is valid only when all of the following hold:

1. at least two candidates remain live;
2. its state, remaining query multiplicities, erasure flag, budget, and
   initial-action flag are encoded canonically;
3. every informative admissible query affordable at that node appears once;
4. each listed query names one response/erasure child generated by the exact
   fault update rule;
5. the child has a valid refutation node at budget reduced by the query cost;
6. a leaf has no informative admissible query that can make every legal child
   feasible within the remaining budget.

The certificate must be content-addressed from canonical node encodings. An
independent standard-library verifier must import zero THEORICA modules and
validate all state transitions, coverage of every admissible query, node
hashes, and the root claim without invoking an optimizer.

## Controls and falsification

- Generate and verify certificates for all three minimal obstruction pairs.
- Confirm each pair is feasible at budget 18.
- Confirm all six singleton deletions are feasible at budget 17 and therefore
  cannot produce a valid budget-17 refutation root.
- Report certificate node/edge counts, maximum depth, root hashes, and the
  initial-query adversarial responses.
- Mutate one child reference, one residual budget, and one state coordinate;
  the independent verifier must reject all three corrupted certificates.

## Stop conditions

Stop and preserve a negative result if the certificate is too large for a
reviewable repository artifact, if the independent verifier finds an invalid
transition, or if any singleton deletion is independently infeasible at 17.
Do not weaken the claim to a search-state count.

## Scope

Success proves a finite lower-bound certificate for these three ten-word
families only. It does not by itself establish a global ternary cost face or
an analytic adversary for arbitrary costs, alphabets, or candidate families.
