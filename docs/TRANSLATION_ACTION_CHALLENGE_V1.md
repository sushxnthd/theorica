# Translation-Action Challenge v1

**Freeze date:** 25 September 2026

## Goal

Test whether THEORICA's translation-base reconstruction transfers from the
11-operation Binary Operation Completion panel to a substantially larger public
catalogue of independently curated finite algebraic structures.

This benchmark is frozen before reading its holdout results.

## Public sources

### GAP SmallGrp

The GAP Small Groups Library is used as a source of finite group multiplication
tables. The benchmark exports every group at the frozen orders:

- development: 24, 32
- holdout: 36, 40, 48

Groups are retrieved using public SmallGrp identifiers and converted to complete
multiplication tables only for benchmark generation/scoring. The learner never
receives the SmallGrp id, structure description, generators, or group label.

### GAP RightQuasigroups

The public `SmallQuandle` catalogue is used as a second source.

Frozen deterministic samples:

- development: 25 order-6 quandles, 25 order-7 quandles;
- holdout: 25 order-8 quandles, 25 order-9 quandles.

The package convention makes right translations the natural permutation
actions. The exported quandle multiplication tables are therefore transposed
before learning so that the same mathematical actions are represented as
THEORICA's left translations. This is a convention alignment, not a learned
or hidden label.

No quandle property or family name is passed to the learner.

## Eligibility is scoring-only

For each full external table, the benchmark scorer computes whether it satisfies
the exact frozen compact-action promise:

1. all learner-side left translations are permutations;
2. the carrier-to-translation map is faithful;
3. the group generated by all translations has at most 20,000 elements;
4. its greedy permutation base has size at most 12.

This full-table eligibility label is never exposed to the learning procedure.
It is used only after a run to score correct reconstruction versus abstention.

## Frozen learner

Parameters:

- maximum acquired full translation rows: 8;
- maximum generated action-group size: 20,000;
- maximum base size: 12;
- fresh validation queries: 64;
- three acquisition seeds per public algebra.

A result counts as successful on an eligible case only when the full reconstructed
table is exactly equal to the hidden public table.

An ineligible case counts as a correct outcome only when the learner abstains.

## Same-representation acquisition baseline

The baseline uses the **same**:

- translation representation;
- permutation-group closure;
- base computation;
- signature matching;
- acceptance/rejection logic;
- validation budget.

The only difference is the acquisition rule after the current representation is
incomplete:

- THEORICA queries a translation implicated by unresolved/colliding signatures;
- baseline queries a uniformly random unqueried translation row.

This isolates whether representation-aware experiment selection contributes
query savings beyond the representation itself.

## Frozen primary gates

The holdout run must satisfy:

1. zero false acceptances on ineligible public structures;
2. exact reconstruction on every eligible holdout case;
3. median table-query fraction below 25% over eligible holdout cases.

Failure of a gate is a benchmark result. The gate will not be relaxed after
seeing the holdout.

## Files

- `scripts/export_gap_translation_challenge.g`
- `scripts/translation_action_challenge_v1.py`
- `.github/workflows/translation_action_challenge_v1.yml`

The workflow installs GAP, SmallGrp, and pinned RightQuasigroups 0.9.12 in a
clean Ubuntu runner, exports the catalogue, runs THEORICA and the random-row
baseline, and uploads the exact corpus and JSON result artifact.
